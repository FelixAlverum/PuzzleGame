# apps/

Anwendungen, die ausgeliefert werden. Noch leer.

| Ordner | Aufgabe | Phase |
|---|---|---|
| `web/` | Plattform-Hülle: Routing, Bibliothek, Profil, Shop, Login, globale Einstellungen. Lädt Spiele per `import()` und übergibt ihnen `platform`. | 1 |
| `api/` | Backend: Konten, Spielstände (Sync mit Revision), Ranglisten mit Nachspiel-Prüfung, Käufe und Entitlements | 3 |

Details: [docs/architektur.md](../docs/architektur.md), [docs/daten-und-konten.md](../docs/daten-und-konten.md).
